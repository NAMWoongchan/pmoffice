# 고성능 전원 관리: 연속 작업과 배터리 보호

[테크 목차](README.md) · [피엠오피스 홈](/index.md)

기업·공공기관에서 문서 작성과 자료 분석을 연속 수행하는 담당자를 위한 PC 전원 설정 해설입니다. 작업 중단과 자료 손실을 줄이기 위해 설정 내용과 적용 조건, 복원 방법을 확인하십시오.

## 1. 목표와 적용 범위

사용자와 AI 도구의 연속 작업을 위해 유휴 상태에서 디스크·화면을 끄거나 자동 절전으로 전환하는 타이머를 해제하고, CPU 전원 정책을 성능 우선으로 구성합니다. 배터리 사용(DC)과 전원 연결(AC)에 같은 값을 저장합니다. 이 프로필은 배터리 수명 최대화보다 작업 중단 최소화를 우선하는 사용자 선택입니다.

아래 변경 전·후 값은 2026-10-11 로컬 powercfg 조회에 기반한 적용 사례입니다. PC 식별정보·진단 원본은 공개 문서에 포함하지 않습니다. 다른 PC의 기본값이라고 일반화하지 않습니다. 설정 저장 확인과 실제 동작·성능 검증은 별도입니다. [S1]

## 2. 고급 옵션 설정값과 해설

변경 전 값은 AC / DC 순서입니다. 최종값은 양쪽 공통입니다.

| 항목 | 변경 전 AC / DC | 최종 AC·DC | 의미와 작업 영향 |
|---|---|---|---|
| 다음 시간 이후 하드 디스크 끄기 | 30초 / 30초 | 0: 사용 안 함 | 디스크 유휴 타이머를 해제합니다. 화면에는 분 단위 반올림으로 1분이 표시됐으며 원래 조회 단위는 초였습니다. SSD·NVMe·장치 자체 절전까지 모두 해제한 것으로 해석하지 않습니다. [S1][S2] |
| 디스플레이 끄기 | 10분 / 4분 | 0: 사용 안 함 | 입력이 없어도 전원 계획의 자동 화면 끄기 타이머로 화면이 꺼지지 않도록 합니다. 밝기·보안 잠금·앱 오류를 제어하는 항목은 아닙니다. [S1] |
| 다음 시간 후 절전 | 10분 / 4분 | 0: 사용 안 함 | 일반 유휴 절전 타이머를 해제합니다. 수동 절전 버튼과 배터리 위험 동작은 별도입니다. [S1][S3] |
| 시스템 무인 절전 시간 제한 | 2분 / 2분 | 0: 사용 안 함 | 사용자 부재 상태로 자동 깨어난 뒤 재절전하는 숨김 타이머도 해제합니다. 보이는 일반 절전 항목만 변경한 경우와 구분합니다. [S1, 로컬 숨김값 조회] |
| 유휴 최대 절전 시간 | 0 / 0 | 0 유지 | 시간이 흘렀다는 이유로 최대 절전하지 않습니다. 최대 절전 기능 자체는 끄지 않습니다. [S1] |
| 덮개 닫기 | 절전 / 절전 | 아무 작업 안 함 | 덮개를 닫아도 이 동작으로 절전하지 않습니다. 내부 패널이 물리적으로 꺼지거나 외부 모니터 구성이 달라지는 현상은 화면 타이머와 별개입니다. [S1, 로컬 조회] |
| 최소 프로세서 상태 | 100% / 5% | 100% | CPU의 최소 성능 상태 정책을 높입니다. CPU 사용률을 100%로 만드는 명령이 아니며, 보장된 고정 클럭·최대 터보 주파수라는 뜻도 아닙니다. [S4] |
| 최대 프로세서 상태 | 100% / 100% | 100% 유지 | 전원 계획의 최대 성능 상태를 100%로 허용합니다. 실제 주파수는 온도·전력 한계·펌웨어·부하에 영향을 받습니다. [S5][S6] |
| CPU 효율 클래스 1·2 최소/최대 | 최소 100% / 5%; 최대 100% / 100% | 모두 100% | 조회되는 클래스별 항목도 동일하게 저장합니다. 설정 항목 존재만으로 실제 CPU가 모든 효율 클래스를 갖는다고 단정하지 않습니다. [S6, 로컬 조회] |
| 시스템 냉각 정책 | 활성 / 활성 | 유지 | 조회된 성능 우선 냉각 정책을 유지합니다. 팬 동작은 제조사 구현에 따르며 실제 온도 검증은 별도입니다. [로컬 조회] |
| CPU 부스트·EPP | 적극적 / 적극적; EPP 0 / 0 | 유지 | 기존 성능 선호 정책을 유지합니다. 숨김 부스트 항목 추가 튜닝·오버클럭은 수행하지 않습니다. [S6, 로컬 조회] |
| PCI Express 링크 상태 관리 | 해제 / 해제 | 유지 | 기존 링크 절전 해제값을 유지합니다. 장치의 모든 전력 관리 기능을 제거한 것은 아닙니다. [로컬 조회] |

USB 선택적 절전은 기존 사용 상태를 유지했습니다. 연결 끊김이 실제로 관측되면 해당 장치·드라이버를 별도로 진단합니다. 무선 어댑터와 Intel 그래픽은 사례 PC에서 이미 최대 성능 값이었습니다. 변경하지 않았으며 모든 PC에서 동일 메뉴가 보인다고 보장하지 않습니다.

## 3. CPU·메모리·AI 성능의 정확한 해석

프로세서 상태 비율은 전원 정책이고 작업 관리자 CPU 사용률은 실제 처리 부하입니다. 최소 100%를 설정해도 할 일이 없는 CPU에 일을 강제로 주지 않습니다. 하드웨어·운영체제가 허용하는 성능 범위에서 응답성을 우선하도록 하는 선택입니다. 이 사례에서는 부스트·EPP의 기존 성능 선호값을 유지했습니다. [S4][S5][S6]

전원 옵션에 RAM 사용량을 최대치로 늘려 작업 속도를 보장하는 항목은 없습니다. RAM을 인위적으로 점유하면 가용 메모리가 줄어듭니다. 메모리 용량 변경, 페이지 파일 조정, 프로세스 강제 종료, 서비스 해제는 이 작업의 범위에 포함하지 않습니다. 실제 업무 성능 향상은 동일 자료·동일 작업의 전후 소요시간으로 판단해야 합니다.

클라우드 AI 처리 시간의 개선률은 확인 가능한 근거 없음입니다. 이 구성의 목표는 로컬 PC가 유휴 절전으로 AI 도구 연결을 끊는 원인을 줄이는 것입니다. 인터넷 장애·서버 지연·앱 종료·업데이트 재시작까지 제거하는 설정은 아닙니다.

CPU 최소 100%, 화면 상시 켜짐을 배터리에서도 적용하면 소비전력·발열·팬 소음이 증가하거나 배터리 지속 시간이 짧아질 수 있습니다. 이 사례의 변화량은 측정하지 않았습니다. 성능이 떨어지면 동일 작업과 온도·전력 조건을 비교한 뒤 최소 상태를 낮추는 대안을 검토합니다. [S6][S8]

## 4. 배터리 3% 설정과 경고 한 번의 한계

| 배터리 항목 | 변경 전 AC / DC | 최종 AC·DC |
|---|---|---|
| 배터리 부족 수준 | 6% / 6% | 3% |
| 배터리 위험 수준 | 2% / 2% | 3% |
| 예비 배터리 수준 | 4% / 4% | 3% |
| 배터리 부족 알림 | 켜짐 / 켜짐 | 꺼짐 |
| 배터리 부족 동작 | 아무 작업 안 함 / 동일 | 유지 |
| 배터리 위험 알림 | 켜짐 / 켜짐 | 유지 |
| 배터리 위험 동작 | 최대 절전 / 동일 | 유지 |

부족 알림을 끄고 위험 알림을 유지하는 구성은 서로 다른 부족 경고를 줄이기 위한 선택입니다. 예비 배터리 수준도 3%로 맞추지만 예비 경고는 별도입니다. 기본 전원 옵션에는 알림 횟수, 경고 표시 후 최대 절전 순서, 경고 표시 지속시간을 보장하는 항목이 없습니다. 제조사 알림까지 포함해 정확히 한 번 표시된다는 근거는 확인되지 않았습니다. [S7]

Windows가 위험 배터리 상태에 진입하는 실효 임계값은 펌웨어 ACPI 임계값과 Windows 위험 수준 중 더 높은 값에 영향을 받습니다. 따라서 설정 3%와 실제 3% 도달 시 전환은 구분해야 합니다. 펌웨어 임계값은 이 사례에서 미확인입니다. [S7]

AC·DC에 같은 값을 저장했다는 사실이 전원 연결 중에도 배터리가 3%로 내려가면 반드시 최대 절전한다는 보장은 아닙니다. 실제 전원 상태와 배터리 보고 방식에 따라 이벤트가 발생합니다. 3% 강제 방전·배터리 임계값 시뮬레이션·현재 세션 최대 절전은 시행하지 않았습니다.

최대 절전은 배터리 위험 시 작업 상태를 저장하기 위한 동작입니다. 갑작스러운 방전·배터리 노후·저장 장치 오류에도 작업 저장을 보장한다는 뜻은 아닙니다. 문서와 작업 파일은 평소 저장하십시오. [S3]

## 5. Modern Standby와 절전·최대 절전

| 상태 | 의미 | 이번 정책 |
|---|---|---|
| 작업 상태 S0 | PC가 작업 가능한 상태 | 유지 목표 |
| S0 저전력 유휴 Modern Standby | 지원 장치의 절전 방식 | 자동 유휴 진입 타이머 해제 |
| 전통적 절전 S1–S3 | 메모리 상태를 유지하는 절전 방식 | 사례 PC에서는 지원하지 않음 |
| 최대 절전 S4 | 메모리 상태를 디스크에 저장 | 기능 유지; 배터리 위험 동작에 사용 |
| 하이브리드 절전 | 전통적 절전과 디스크 상태 저장 결합 | 사례 PC에서는 지원하지 않음 |

지원 여부는 powercfg /a의 실제 출력으로 확인해야 합니다. 설정값이 켜져 있어도 하드웨어가 지원하지 않으면 기능 실행 검증으로 볼 수 없습니다. 최대 절전 시간 0은 최대 절전 기능 해제와 다릅니다. [S1][S3]

덮개를 닫은 채 연속 작업할 때에는 제조사 냉각 지침과 통풍 조건을 확인하십시오. 닫힌 덮개와 밀폐된 가방은 서로 다른 환경입니다. 이번 구성은 가방 속 고부하 운전을 승인하거나 온도를 검증한 결과가 아닙니다. 덮개를 닫은 실제 작업·냉각 검증은 물리적 조작을 포함해 별도로 수행해야 합니다. [실무 운영 제안; 장치별 냉각 근거 미확인]

## 6. 화면에서 확인·변경하는 방법

1. 제어판 → 하드웨어 및 소리 → 전원 옵션에서 고성능을 선택합니다.
2. 전원 관리 옵션 설정 변경 → 고급 전원 관리 옵션 설정 변경을 엽니다.
3. 하드 디스크·절전·프로세서 전원 관리·디스플레이·배터리를 펼칩니다.
4. 배터리 사용과 전원 사용을 각각 확인하고 위 표의 값을 입력합니다. 타이머 0은 사용 안 함으로 표시될 수 있습니다.
5. 적용 후 창을 닫고 다시 열어 캐시된 값과 저장된 값을 구분합니다.
6. 덮개 동작은 전원 옵션의 덮개를 닫으면 수행되는 작업 선택 메뉴에서도 확인합니다.

사례 PC는 숨김 무인 절전·CPU 클래스 항목을 전원 관리 도구로 설정했습니다. 메뉴를 보이게 만들기 위한 레지스트리·Attributes 변경은 하지 않았습니다. UI 조작이 불안정할 때에는 허용된 도구로 값을 변경하고 실제 저장값을 재조회합니다. 권한 오류는 정상 또는 성공으로 해석하지 않습니다.

## 7. 변경 전 백업·복원·검증

변경 전 전체 전원 설정을 텍스트·JSON으로 보관하고, 변경 항목을 원래 AC/DC 값으로 되돌리는 복원 절차를 준비합니다. .pow 내보내기가 가능한 환경에서는 전원 계획 파일도 보존합니다. 내보내기 실패로 생긴 0바이트 파일은 유효한 백업이 아닙니다. [S1]

이 사례는 .pow 내보내기가 Windows 권한 오류로 실패하여 전체 값과 복원 스크립트를 보존했습니다. 복원 스크립트의 원래값 대응은 확인했지만, 실제 복원 실행은 수행하지 않았습니다. 보안 권한을 확대하거나 재시작하여 오류를 우회하지 않았습니다.

| 검증 | 사례 상태 | 완료 판단 기준 |
|---|---|---|
| AC/DC 설정 저장 | 확인 | 적용 후 대상값 재조회, 고성능 활성 확인 |
| 고급 설정 화면 | 일부 항목 확인 | 새 창에서 값 확인; 모든 항목 화면 확인과 구분 |
| 15분 AC·DC 유휴 | 별도 실동작 확인 필요 | 입력 없는 15분, 전원 상태 및 화면·절전 이벤트 확인 |
| 덮개 닫은 작업 | 별도 실동작 확인 필요 | 통풍 확인 후 물리적으로 닫고 작업 유지 확인 |
| 배터리 3% 동작·경고 횟수 | 미검증 | 안전한 별도 관찰; 이번 작업에서 강제 방전하지 않음 |
| 동일 업무 성능 향상 | 미검증 | 동일 입력·작업의 전후 시간 비교 |
| 실제 복원 성공 | 미검증 | 승인된 원래값 복원 후 재조회 |

DC 실험은 전원 플러그 분리라는 물리적 조작이 필요합니다. 도구로 실제 전원 상태를 확인하지 않았다면 DC 유휴 검증 완료로 기록하면 안 됩니다. 시간 경과만 확인한 결과도 사용자 입력이 없었다는 증거와 구분합니다.
