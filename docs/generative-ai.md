# 실전 AI (Applied AI)

사업계획서 검토, 보고서 작성, 자료 분석과 반복 업무에 생성형 AI를 활용하기 위한 학습 주제를 안내합니다. 아래 주제는 순차적으로 보완합니다. [분류 설계 근거: 제공 교재](https://docs.google.com/document/d/1uwurHY4hVby3HCqTQrf4UYp8QxR4RJuh/edit)

| 분류 | 향후 작성 주제 |
|---|---|
| 프롬프트(Prompting) | 목표·입력·제약·완료 기준 작성 |
| 컨텍스트(Context) | 필요한 자료·전제·근거 연결 |
| 검색 증강 생성(RAG) | 문서 검색·근거 선택·답변 검증 |
| 에이전트(Agent) | 책임·입출력·권한·검토와 인계 |

## 작성과 검토

개념과 제품별 기능을 분리합니다. 제품·모델·요금·사용 제한 등 변할 수 있는 정보는 공식 자료와 확인일을 기록합니다. 실행하지 않은 자동화나 실험하지 않은 성능을 검증 완료로 표시하지 않습니다.
