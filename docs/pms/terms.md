# 회원 서비스 이용·개인정보 안내

가입 안내 버전: member-v1.1

피엠오피스의 회원 지식 자료와 고객 프로젝트 일정·현황·보고서를 이용하는 서비스입니다.

- Google 계정 또는 이메일·비밀번호로 가입하고 로그인할 수 있습니다. 이메일 인증은 요구하지 않습니다.
- 직접 가입하는 회원은 이메일·이름과 비밀번호를 입력합니다. 기업·기관 회원은 회사명·소속을 입력하며 개인 회원의 소속은 선택 사항입니다.
- 관리자가 기업 고객 등의 회원정보를 직접 등록할 수 있습니다. 관리자 등록 사실과 회원 본인의 가입 동의 기록은 구분하여 보존합니다.
- 계정 식별 정보, 이메일, 이름, 회사·소속, 가입 경로·확인 상태, 그룹과 자료 접근 권한을 회원 관리와 서비스 제공에 사용합니다. 비밀번호 원문은 회원정보·관리 이력에 보관하거나 표시하지 않습니다.
- 활성 회원은 일반 지식 자료를 읽을 수 있습니다. 기존 VIP 자료와 보호 강의의 별도 이용 조건은 유지합니다.
- 고객 프로젝트는 관리자가 연결한 그룹의 유효한 구성원만 이용할 수 있습니다. 가입만으로 고객 프로젝트 접근 권한이 부여되지는 않습니다.
- 회원에게 가입·정보 변경 등의 자동 알림 메일을 보내지 않습니다. 관리자는 필요한 경우 그룹 또는 회원을 선택하여 직접 메일을 보낼 수 있습니다. 새 가입·문의 접수 알림은 시스템 관리자에게만 전달합니다.
- 로그인 후 내 정보에서 회원정보와 PMOffice 비밀번호를 수정할 수 있습니다. Google 계정 자체의 비밀번호는 Google에서 관리합니다. 비밀번호를 잊은 경우 관리자에게 문의해 주세요.
- 관리자의 탈퇴 처리는 사이트 이용과 접근 권한을 중지하며 회원정보와 처리 이력은 보존합니다. 회원정보 정정·이용 종료·개인정보 삭제 요청은 아래 연락처로 문의해 주세요.
- 내려받은 원본과 보고서는 해당 프로젝트의 업무 목적과 제공 범위에 맞게 이용해 주세요.
