# 프로젝트 서비스 이용 안내

피엠오피스의 고객 프로젝트 일정·현황·보고서를 확인하는 서비스입니다.

- Google 계정으로 로그인하고 회원 가입 확인을 마치면 가입 회원용 프로젝트를 이용할 수 있습니다.
- 지정 회원 프로젝트는 운영자가 해당 프로젝트의 접근을 허용한 회원만 이용할 수 있습니다.
- 계정의 식별 정보·이메일과 가입 확인 상태, 프로젝트 접근 권한을 회원 관리에 사용합니다.
- 다운로드한 원본과 보고서는 해당 프로젝트의 업무 목적과 제공 범위에 맞게 이용해 주세요.
- 회원 정보·이용 종료·접근 권한 관련 문의: [피엠오피스 문의](/contact.html).
