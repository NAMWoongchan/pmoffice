# 피엠오피스 E-book 생성기

개인 폴더에 PDF·PowerPoint를 올려 온라인 이북으로 관리하고 공유합니다.

현재 시험 운영 준비 중입니다. 운영 한도와 대표 자료 검증을 마친 뒤 이용할 수 있습니다.

[이북 서비스 열기 →](https://ebooks.pmoffice.co.kr/)

- 기존 피엠오피스 Google·이메일 계정을 사용합니다.
- 이북을 연 뒤 **전체 화면** 버튼을 누르면 메뉴를 접고 화면 가득 읽을 수 있습니다. **Esc**로 돌아옵니다.
- 공유받은 이북도 같은 주소에서 권한을 확인한 후 전체 화면으로 볼 수 있습니다.
- 파일당 50 MiB·200쪽, 회원당 10권을 목표 한도로 제공합니다.
- 새 이북은 비공개이며 소유자가 공유 범위를 선택합니다.
- 원본은 소유자·시스템 관리자만 내려받을 수 있습니다.
- 삭제한 자료는 열람을 중지하고 관리자 보관함에 남습니다.
