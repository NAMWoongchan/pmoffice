# 프로젝트 관리 (Project Management)

PMOffice의 프로젝트 관리 지식을 정리할 분야 안내입니다. 아래는 작성 예정 분류이며 실제 방법론 해설이나 검증된 실무 사례가 아닙니다. [분류 설계 근거: 제공 교재](https://docs.google.com/document/d/1uwurHY4hVby3HCqTQrf4UYp8QxR4RJuh/edit)

| 분류 | 향후 작성 주제 |
|---|---|
| 범위(Scope) | 목표·산출물·포함 및 제외 범위 |
| 작업분류체계(WBS) | 산출물 기반 작업 묶음과 완료 기준 |
| 일정(Schedule) | 선후행 관계·달력·마일스톤 |
| 원가(Cost) | 추정 근거·예산·변경 영향 |
| 위험(Risk) | 원인·사건·영향·대응 |
| 품질(Quality) | 인수 기준·검토·검증 기록 |

## 작성 전 확인

각 주제의 공식 자료와 적용 범위를 확보한 뒤 본문을 작성합니다. 기간·예산·담당자·표준 요구사항은 근거 없이 입력하지 않습니다. 본 페이지의 전문 해설과 실무 사례는 아직 작성하지 않았습니다.
