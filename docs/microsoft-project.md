# MS Project (Microsoft Project)

Microsoft Project의 일정·자원·기준선 지식을 정리할 분야 안내입니다. 아래 목록은 작성 예정 주제입니다. [분류 설계 근거: 제공 교재](https://docs.google.com/document/d/1uwurHY4hVby3HCqTQrf4UYp8QxR4RJuh/edit)

| 분류 | 향후 작성 주제 |
|---|---|
| 일정 작성(Scheduling) | 작업 입력·선후행 관계·달력·작업 유형 |
| 자원 배정(Resource Assignment) | 자원 단위·작업량·배정에 따른 기간 변화 |
| 기준선(Baseline) | 기준선 저장·진척 비교·변경 이력 |

## 적용 범위와 검증

실제 문서 작성 시 제품 이름·버전·예약 방식·달력 등 전제를 기록합니다. 사용자가 실행한 결과와 교재의 예상 결과를 구분합니다. 이번 초기 구축에서는 Microsoft Project를 실행하거나 MPP 호환성을 검증하지 않았습니다.
